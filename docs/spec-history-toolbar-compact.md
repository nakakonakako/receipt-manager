# 履歴画面のコンパクトなツールバー

履歴の上部を「何を見ているか」と「どう探すか」の2段に整理する。PCの左サイドバーと既存のスクロール挙動は維持する。

- 1段目は左にアイコンのないレシート／キャッシュレス切替、中央に月送りと月選択、右に小さなラベルと強調した合計金額を置く
- 2段目は検索欄、検索範囲、並び順を置く。狭い画面では折り返し、主要操作のタップ領域を約44px確保する
- 月ボタンのポップオーバーでは年を選び、その年に存在する月だけを表示する。候補は選択中の種別の月に限定し、外側クリックまたは月選択で閉じる
- 履歴行の日付と金額を強調し、編集・削除・展開は補助操作として扱う
- 検索、検索範囲、並び順、種別ごとの月、前後移動、合計、編集・削除・明細展開の既存動作を維持する。全期間では従来通り月選択と合計を表示しない
