# 履歴画面の月別表示と全期間検索

通常は選択中の種別・月の取引を表示し、月別合計は検索語や並び順にかかわらず、その月の全取引を合算する。種別ごとに月選択を保持し、年を選んで利用可能な月を選択できる。

検索欄への入力は下書きで、Enterまたは検索ボタンで選択中の種別の全期間を検索する。検索結果には件数を表示し、月別合計や検索結果の合計は表示しない。解除すると元の月別表示に戻る。検索中も種別と並び順を変更できる。

検索は既存の月別取得を再利用し、取得済みと進行中の月を共有する。未取得の月は順次読み込み、処理中・失敗・結果なしを表示する。画面条件の変更後、古い要求の完了を現在の表示状態として扱わない。大量の月がある場合は検索開始に時間がかかる。

PCでは種別、月、月別合計を関連付け、検索と並び順を別の領域に置く。スマートフォンでは自然に縦に並べ、主要操作のタップ領域と横幅を確保する。既存のサイドバー、スクロール、編集・削除と明細展開を維持する。
