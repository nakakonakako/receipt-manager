# 履歴画面の月別表示と全期間検索

通常は選択中の種別・月の取引を表示し、月別合計は検索語や並び順にかかわらず、その月の全取引を合算する。種別ごとに月選択を保持し、年を選んで利用可能な月を選択できる。

検索欄への入力に応じて選択中の種別の全期間を検索する。検索結果には件数を表示し、月別合計や検索結果の合計は表示しない。解除すると元の月別表示に戻る。検索中も種別と並び順を変更できる。

検索は既存の月別取得を再利用し、取得済みと進行中の月を共有する。未取得の月は順次読み込み、処理中・失敗・結果なしを表示する。画面条件の変更後、古い要求の完了を現在の表示状態として扱わない。大量の月がある場合は検索開始に時間がかかる。

PCでは月別合計を上段中央に置き、その下に種別切替、月送り、検索欄の開閉と並び順を配置する。検索ボタンで入力欄を次の行に開き、閉じると検索を解除する。スマートフォンでは月別合計、中央揃えの月送り、種別切替と検索・並び順の順に並べる。種別切替と操作ボタンは同じ行を優先し、狭い幅では折り返してタップ領域を確保する。既存のサイドバー、スクロール、編集・削除と明細展開を維持する。

月別合計と操作列の間に淡い区切り線を置き、PCの履歴行は日付・店舗名・金額・補助操作をコンパクトに横一列で表示する。スマートフォンの履歴カードは日付と編集・削除、店舗名と金額の2行とし、長い店舗名だけを省略する。レシートの明細はカード本体から展開し、展開状態を支援技術に伝える。
