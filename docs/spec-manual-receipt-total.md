# 手動入力の合計金額

手動入力では、空欄を0円とした商品金額の合計に調整額を加え、表示と保存に同じ値を使う。調整額の初期値は0円。合計を直接編集すると、その時点の商品合計との差額を調整額として保持し、以降の商品追加・変更・削除にも引き継ぐ。調整額が0円のときは調整額行を表示しない。保存成功またはキャンセル後は新しい入力として初期化する。

OCR確認では抽出された合計を初期値とし、商品金額の変更で合計を自動更新しない。従来どおり合計の直接編集と差額表示ができる。

手動入力とOCR確認のいずれでも、新しく追加した商品の金額は空欄で、0はプレースホルダーとして表示する。空欄のまま保存すると金額は0円になる。既存商品の金額は維持する。
